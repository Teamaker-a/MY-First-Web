# 01 · 需求与网站结构

> 2026-10-20 确认的第一版需求；2026-10-22 按法式烫金 / 复古手账参考更新视觉方向。

## 网站三块内容

1. **Coding 作品**：个人写过的项目，卡片列表 + 项目详情（截图、技术栈、链接）。
2. **旅行地图（游戏化）**：网站的重点互动区。
3. **个人文章**：记录感悟、学习笔记、使用 AI 的方法等，列表 + 文章详情。

## 旅行地图的完整体验

1. **开局**：一个卡通地球，自动缓慢旋转，可以用鼠标拖动、滚轮缩放。
2. **点击地球**：镜头拉近 / 过渡，展开中国地图。
3. **中国地图颜色规则**：
   - 去过的地方：粉色，透明度 60%
   - 没去过、但目前最想去的地方：蓝色，透明度 60%
   - 其他省份：中性底色，弱化处理
4. **点击一个地方**：
   - 弹出该地的旅行照片
   - 照片用 **3D 童话旋转木马** 的形式呈现（环形排列、可旋转、有童话装饰）
   - 附带背景音乐
5. **返回**：可以从目的地返回中国地图，再返回地球。

## 视觉方向（2026-10-22 当前方案）

全站统一复古高级调性，低饱和、柔和、不做刺眼效果；所有正文区域必须清楚可读，装饰只放在页边或卡片边缘。

### 模块一：首页 · 法式烫金花卉

- 深墨黑底（偏暖），四角金线 / 香槟金花卉向中间生长，中心留白。
- 花卉意象：牡丹 + 兰花；香槟金 + 米白花瓣，细金线描边。
- 中心：小圆形 S 字标、名字「沈旭斐」、短句、三条栏目入口。
- 字体：WenKai 大字 + Georgia / 衬线小字；不使用无衬线大标题。
- 动效：标题分层入场（模糊 / 字距 / 上移），四角花卉慢浮动 + 鼠标视差，入口链接细金线 hover。
- 实现：`index.html`、`css/home.css`、`js/home.js`、`assets/images/home/floral-corner.svg`。

### 模块二：内页 · B「博物图鉴」（2026-10-29 用户选定）

- 深鼠尾草绿旧纸底，低饱和；奶油色图版、暗金细线、旧纸、胶带、撕边、蕾丝都在边缘。
- 元素：白百合、铃兰、天鹅、蕨类、鼠尾草蝴蝶、旧信纸、邮票、蕾丝、旧书 / 图鉴版画。
- 作品页：三张带胶带的奶油纸图版，封面分别是白百合 / 蕨类 / 蝴蝶；项目信息、标题、描述保持清晰；右下角是 `CYGNUS OLOR` 天鹅便签。
- 写作页：深绿旧纸上的三张奶油信笺，带 `PLATE I/II/III` 邮票标签和植物边缘；中间留白，文字放在米色纸片上；点开进入文章。
- 文章页：一张撕边图鉴纸页，暗金内框、HERBARIUM 邮票、白百合 / 蕨类 / 旧信封边缘；正文用衬线大字、首行缩进、右下落款和金色火漆。
- 动效：慢速入场、卡片轻微错落、鼠标分层视差、蝴蝶慢浮动；不使用强烈弹跳。
- 实现：`css/scrapbook.css`（版式底层）+ `css/natural-history.css`（B 皮肤）、`js/pages.js`、`js/writing-room.js`。
- 旧的浅裸粉手账方向已被 B 取代；粉色信纸素材保留，但当前不参与页面。

## 技术方案（第一版）

- 纯静态 HTML / CSS / JS，方便部署。
- 地球：Three.js（本地 vendored），球体贴图用世界 GeoJSON 在 Canvas 上绘制卡通大陆。
- 中国地图：DataV 中国省份 GeoJSON，运行时投影成 SVG，按数据上色，支持 hover / click。
- 照片木马：CSS 3D 环形旋转木马（`preserve-3d`），支持自动旋转、拖动、上一张 / 下一张。
- 过渡动画：GSAP（本地 vendored）。
- 背景音乐：原型用 WebAudio 合成的音乐盒循环，之后替换成用户提供的音频文件。
- 数据：`site/js/data.js` 里集中管理去过 / 想去的省份、照片、作品、文章；先放占位数据，方便替换。
