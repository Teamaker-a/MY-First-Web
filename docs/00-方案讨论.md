# 00 · 方案讨论

> 这一步只定方向，不做页面。先选一个主题，再准备素材。

## 先确认的 5 件事

1. **网站给谁看？** 课程作业展示 / 求职作品集 / 个人表达 / 给朋友看
2. **放哪些作品？** 建议 3–6 个，先列名称，每个一句话说明
3. **你是谁？** 名字或昵称、一句话介绍、联系方式（邮箱 / 小红书 / 微信）
4. **喜欢什么？** 3 个喜欢的网站或图片（链接 / 截图都行）
5. **做到什么程度？** 只要桌面端，还是手机也要；中文还是中英双语

## 三个方向

### A. 排版实验室（Editorial Lab）· 推荐

把自己的排版作业、版式练习、字体实验当成作品，用「编辑设计」的语言做网站。

- **视觉**：米白纸感底、黑色大字、一个强调色（朱红 / 墨绿）、细网格线、页码、裁切标记
- **首页**：超大名字或一句话 + 精选作品（像杂志目录）+ 关于 / 联系
- **内页**：作品像对页一样展开，配课程、年份、尺寸、角色；保留过程稿和网格
- **动效**：标题字重 / 字距变化；滚动时网格线出现；图片像印刷套准一样错位后归位；页面切换像翻页
- **素材**：你的对页作业图、局部细节、纸张纹理、网格截图
- **适合**：新媒体 / 排版方向，辨识度高，能直接复用你已有的课程作业

### B. 日常档案（Personal Archive）

像一本会动的剪贴簿，展示照片、文字、票根、随手记。

- **视觉**：暖色、拍立得、胶带、手写便签、时间线
- **首页**：一句自我介绍 + 最近三条记录 + 时间线入口
- **内页**：按月份 / 主题归档，照片可以拖动、翻看
- **动效**：便签轻微摇晃、照片翻面、滚动时纸张层叠
- **素材**：手机照片、扫描件、手写文字、票根
- **适合**：想长期更新、偏个人表达，不太像求职作品集

### C. 干净作品集（Clean Portfolio）

最稳妥的作品集：大图、少文字、项目卡片、清楚的联系方式。

- **视觉**：白底、无衬线、粗细对比、留白、统一的项目封面
- **首页**：名字 + 一句话 + 3 个精选项目 + 关于
- **内页**：项目背景、过程、结果，图片为主
- **动效**：图片视差、项目卡片 hover、页面淡入
- **素材**：每个项目 3–6 张图 + 一段说明
- **适合**：找实习 / 求职，信息清楚，制作周期短

## 推荐组合

**A 的视觉 + C 的信息结构**：用「排版实验室」的纸感、网格和大字建立辨识度，但作品详情保持 C 的清楚结构（背景 → 过程 → 结果）。这样既有个人风格，也能给别人看作品。

## 第一版页面结构（建议）

```
首页
├─ 名字 / 一句话
├─ 精选作品 3 个
├─ 关于我（短）
└─ 联系方式
作品列表
└─ 全部作品（可按课程 / 类型筛选）
作品详情
├─ 封面
├─ 项目信息（课程、年份、角色、工具）
├─ 过程图 3–5 张
└─ 上一件 / 下一件
关于
└─ 自我介绍、经历、技能、联系方式
```

## 素材清单（确认方向后按这个准备）

**作品图**
- 每个作品 1 张封面（建议 1600×1200 或 1600×900）
- 每个作品 3–5 张细节 / 过程图
- 图片尽量清晰，命名用英文 / 拼音，例如 `work-01-cover.jpg`

**文字**
- 网站标题（名字或昵称）
- 一句话介绍（20 字以内）
- 每个作品：名称、一句话说明、课程 / 年份 / 角色 / 工具
- 关于我：100–200 字
- 联系方式：邮箱 / 小红书 / 其他

**可选**
- 头像或工作照
- 纸张纹理、胶带、线条等装饰素材（透明底 PNG / SVG）
- 3–10 张参考图（网站截图、海报、配色）
